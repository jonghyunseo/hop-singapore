# hop 0.2.0

- **전체 화면 지도**: 지도 위에 검색, 하차역 카드, 플로팅 메뉴를 배치했습니다. 선택한 장소와 가까운 역은 카드에 가리지 않는 위치에 표시됩니다.
- **컴팩트한 메뉴**: 가로형 하단 메뉴와 간결한 장소 목록. 상세 정보와 가까운 역 3곳 비교는 시트를 펼쳐 확인합니다.
- **Google 지도 즐겨찾기 가져오기**: Google Takeout의 Saved ZIP/CSV와 GeoJSON을 읽습니다. 메모와 목록 이름을 유지하고, 좌표가 없는 항목은 검색 결과나 지도 핀으로 확인할 수 있습니다.
- 확인된 장소만 먼저 저장할 수 있으며, 남은 항목은 검토 목록에 유지됩니다. 동일 장소는 중복 제외합니다.

## 설치

아래 `hop-0.2.0.apk`를 설치하세요. Android 8.0 이상, 단일 APK입니다. 0.1.1 배포판 위에 설치하면 기존 장소와 메모가 유지됩니다.

**Obtainium 소스:** https://github.com/jonghyunseo/hop-singapore

## Google 즐겨찾기

저장한 곳 → Google 지도 즐겨찾기 가져오기 → Google Takeout에서 Saved(저장됨) 내보내기 → 다운로드한 ZIP 또는 CSV 선택.

Google 계정 자동 동기화·목록 공유 링크 전체 가져오기는 지원하지 않습니다. 좌표 없는 장소는 확인 후 저장하며, 온라인 검색이 안 되면 지도 핀·좌표를 사용할 수 있습니다. 단일 파일 2MB, ZIP 압축 전후 각 20MB, 한 번에 1,000곳까지 지원합니다.

## 확인

핵심 단위 테스트 7개와 릴리스 빌드·필수 lint 통과. Android 16 에뮬레이터에서 전체 화면 지도, 역 비교, ZIP 선택·부분 저장·좌표 없는 장소 보완·재실행 후 저장 유지 확인. 실제 개인 Google 계정의 전체 목록에 대한 포괄 검증은 포함하지 않습니다.
