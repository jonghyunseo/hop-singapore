# hop 0.3.0

비어 보이던 기본 지도를 도로·건물·상점 이름이 표시되는 상세 지도로 바꿨습니다.

- **상세 지도 기본 활성화**: MapLibre Native + OpenStreetMap 지도 위에 MRT 노선과 저장 장소 표시. 이전 버전에서도 업데이트 후 기본 활성화됩니다.
- **장소·주소·MRT 검색**: 오프라인 역/저장 장소 검색, 온라인 장소 검색, 최근 검색.
- **주변 탐색**: 음식점·카페·관광지·쇼핑몰·숙소를 지도 중심 2.5km 안에서 최대 20곳 찾고 지도·목록으로 확인.
- **지도 조작**: 이동, 핀치/두 번 탭 확대, 회전, 북쪽 정렬, 축척, 전체 보기, 장소와 하차역 범위 맞춤.
- **장소 선택·저장**: 지도 탭/길게 누르기, 좌표·주변 주소 확인, 검색한 장소 저장, 역 정보 카드.
- **내 위치 추적**: 사용자가 켠 동안 위치 표시. 지도 이동 또는 앱이 보이지 않을 때 추적 중단.
- **길찾기·공유**: 현재 위치 또는 가까운 역에서 도보·대중교통·자동차 경로를 Google 지도에서 열기. 장소 링크 공유.
- **지도 표시 설정**: 상세 지도·MRT·저장 장소 토글, 연결 상태·재시도, 캐시된 지도와 오프라인 MRT 표시.
- 전체 화면 지도와 둥근 플로팅 메뉴 유지. 세로/가로 화면의 버튼 겹침 정리.

## 설치

아래 **hop-0.3.0.apk**를 설치하세요. Android 8.0 이상, 단일 APK입니다. 기존 배포판 위에 설치하면 저장 장소·메모가 유지됩니다.

**Obtainium 소스:** https://github.com/jonghyunseo/hop-singapore

## 사용 범위

상세 지도와 새 장소 검색에는 인터넷이 필요합니다. 아직 캐시하지 않은 지역의 상세 지도는 오프라인에서 보이지 않습니다. 경로 안내는 Google 지도에서 열리며 앱 내부 내비게이션·실시간 교통·위성사진·스트리트뷰는 포함하지 않습니다.

Google 지도 즐겨찾기 가져오기는 기존처럼 Takeout ZIP/CSV/GeoJSON 파일로 제공합니다. 계정 자동 동기화는 지원하지 않습니다.

## 확인

핵심 단위 테스트 9개 통과. release 빌드·필수 lint·서명 확인 성공. Android 16 전용 에뮬레이터에서 상세 지도 렌더링, 장소/MRT 검색, 주변 카페 탐색·저장·재실행 유지, 위치 표시·추적, 오프라인 역 검색과 세로/가로 화면을 확인했습니다. 물리 기기 GPS 정확도와 외부 Google 지도의 경로 품질은 검증하지 않았습니다.
