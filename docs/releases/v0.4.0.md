# hop 0.4.0

**다른 앱에서 공유하면 바로 여행에 보관됩니다.** 좌표를 확인하거나 내보내기 파일을 만들지 않아도 됩니다.

- Google 지도·브라우저·예약 앱의 **공유 → hop**: 제목·텍스트·링크 즉시 저장.
- **Google 지도 목록도 링크로 보관하고 원문 보기**. 앱에서 연 브라우저 탭으로 확인하고 돌아올 수 있습니다.
- 하단 **여행** 화면: 공유함 / 일정 / 장소. 기존 저장 장소는 유지됩니다.
- **날짜·시간·메모·예약번호** 추가, 중요 고정, 검색, 완료 체크, 삭제 실행 취소.
- **중복 공유 시 기존 일정·메모 유지**.
- **장소 연결**: 저장한 장소를 선택하거나 새 장소를 확인하고 MRT 지도 연결. 기존 장소를 바로 여행 일정에 추가할 수도 있습니다.
- 링크·메모 직접 추가, 명시적 붙여넣기, 원문 다시 공유, 공유한 앱으로 돌아가기.
- 파일 가져오기는 메뉴의 보조 기능으로 유지합니다.

## 설치

아래 **hop-0.4.0.apk**를 기존 앱 위에 설치하세요. Android 8.0 이상, 같은 서명 키의 단일 APK입니다.

**Obtainium 소스:** https://github.com/jonghyunseo/hop-singapore

## 사용 범위

단일 싱가포르 여행 보관함이며 날짜·시간은 싱가포르 현지 기준입니다. Google 목록 전체 자동 추출·계정 동기화, 이메일 자동 읽기, 이미지/PDF 첨부, OCR은 포함하지 않습니다. 원본 웹페이지는 인터넷과 해당 서비스 로그인이 필요할 수 있습니다. 원문 텍스트·제목·메모·일정은 기기에 저장됩니다.

[벤치마크와 시스템 설계](https://github.com/jonghyunseo/hop-singapore/blob/main/docs/travel-system-v0.4.md)

## 검증

핵심 단위 테스트 12개 통과. Android 16 에뮬레이터에서 시스템 공유 시트 수신, 원문 페이지 열기, 일정·메모·중복 보존, 지도 연결, 오프라인 텍스트 보관, 삭제 실행 취소, 재실행 복원을 확인했습니다. 서명된 release 빌드와 필수 lint 검사를 통과했으며 이전 배포판과 같은 서명 키를 사용합니다.
